# 🎮 休み時間パーティー！ (School Party Games)

スマホ1台を机に置いたり、順番に回したりして学校の休み時間や暇な時間に友達と盛り上がれるミニゲーム集Webアプリです。

インストール不要で、スマホのブラウザですぐに遊べます。音のON/OFFもワンタップで切り替え可能です。

---

## 🌟 収録ゲーム一覧

### 1. 💥 連打クラッシュ！（2人対面）
* **操作**: スマホを机の真ん中に置き、向かい合って自分の陣地を猛連打！
* **ルール**: 中央のラインを相手陣地の奥まで押し込んだプレイヤーの勝ち！

### 2. ⚡ 早押しデュエル（2人対面・3本先取）
* **操作**: 画面中央の合図をじっと待つ。
* **ルール**: 「💥 今だ！撃て！」が出た瞬間に自分の画面をタップ！お手つき（早すぎ）は相手にポイントが入るので注意！

### 3. 🐺 ワン端末ワードウルフ（3〜8人・心理戦）
* **操作**: スマホを順番に回して、画面のカードを長押しして自分のお題をこっそり確認（指を離すと隠れます）。
* **ルール**: 1人だけ違うお題（ウルフ）が混ざっています。3分間の雑談タイムで自分が市民かウルフかを探り合い、最後に投票！

### 4. 💣 爆弾チキンレース（2〜8人・パスゲーム）
* **操作**: 画面に表示されたお題（「赤いもの」「学校にあるもの」等）を声に出して答えたら「答えてPASS！」を押して隣の人へパス！
* **ルール**: いつ爆発するかわからないランダムタイマー。手元で「ボカァァン！」と爆発した人の負け！

### 5. 🖐️ フィンガーツイスター（2人対戦・サバイバル）
* **操作**: 画面上に次々と出現する円（赤=P1、青=P2）に指を置き続ける。
* **ルール**: 指が円から離れたり、置けなくなって脱落した方の負け！指が絡まり合って大爆笑必至！

### 6. 🏓 エアホッケー（2人対戦・3点先取）
* **操作**: マレットを指でスライドしてパックを弾き飛ばす。
* **ルール**: 物理演算でリアルに跳ね返るパックを相手ゴールに打ち込め！

### 7. 🪨 スピードじゃんけん（2人対面・5点先取）
* **操作**: 中央のお題（✊✌️🖐️）と「勝て！🔥」「負けろ！🌀」の指示を見る。
* **ルール**: 指示された手（「負けろ」なら負ける手）を瞬時に選ぶ脳トレ・反射神経バトル！

### 8. 🎯 ナイフスロー（2人対面・命中バトル）
* **操作**: 画面をタップして回転する丸太の的にナイフを刺す。
* **ルール**: 相手や自分のナイフに当たるとミス！5本すべて刺し切れるか！？

### 9. 🧠 カラーブレイン（2人対面・4点先取）
* **操作**: 表示された文字の意味と「文字の色」が合っているかを判定。
* **ルール**: 「⭕ 一致」か「❌ 違う」を素早くタップ！脳の混乱に打ち勝て！

### 10. 🚀 スペースドッジ（2人対戦・サバイバル）
* **操作**: 自分の宇宙船を左右にスライド操作。
* **ルール**: 降り注ぐアステロイド群を最後まで回避し続けたプレイヤーの勝ち！

## 🚀 遊び方（GitHub Pages）

GitHubリポジトリの **Settings > Pages** で `Branch: main / Root` を選択することで、Webサイトとして即座に公開され、スマホのブラウザでURLを開くだけで友達みんなで遊べます！
