# 🎮 休み時間パーティー＆ひまつぶし！ (School Party Games & Time Killers)

学校の休み時間や放課後、授業の合間の暇な時間に**1人でも友達とでも盛り上がれる究極の暇つぶし総合Webサイト**です！【全96ゲーム＆機能収録】

インストール・ログイン一切不要！URLを開くだけですぐに遊べます。スマホでもタブレット・PC（Chromebook等）でも快適にプレイ可能。音のON/OFFもワンタップで切り替えできます。

## ✨ 休み時間・暇つぶし特選機能（新登場！）

### 1. 🎒 文房具スイカパズル（1人プレイ・マージ物理パズル）
* **操作**: 画面上部をタップして文房具を落とす。
* **ルール**: 同じ文房具同士がぶつかるとマージ進化！（クリップ ➔ えんぴつ ➔ けしごむ ➔ 定規 ➔ ハサミ ➔ 万年筆 ➔ 三角定規 ➔ ノート ➔ 教科書 ➔ ランドセル ➔ 黄金トロフィー）。溢れないように高得点を目指せ！

### 2. 📊 スプレッドシート迷宮（カモフラージュ・Boss Key付き）
* **操作**: 矢印ボタンやキーボードでスネークを操作し、緑の `=SUM` セルを食べて成長。
* **裏機能**: **「🚨 先生が来た！」ボタン（またはEscキー）**を押すと、一瞬で「第2学期 期末考査 成績集計表」に早変わり！先生の目を盗んで暇つぶしできます。

### 3. 🔤 放課後 Wordle（1人プレイ・日本語5文字言葉当て）
* **操作**: 画面下の50音キーボードで学校・日常に関する5文字の言葉を入力。
* **ルール**: 🟩緑（完全一致）・🟨黄（含まれるが位置違い）・⬜灰（含まれない）の手がかりをもとに、6手以内で正解の言葉を推理！

### 4. ⌨️ 授業中タイピング・マスター（カモフラージュ＆スピード）
* **操作**: 黒板に現れる学校あるある単語をキーボード打鍵 または 候補文字タップで入力。
* **ルール**: 打鍵音とともに爽快なコンボ！打鍵速度（WPM）とタイムを計測。

### 5. 🧹 黒板消し＆落書きクリッカー（1人プレイ・無心クリッカー）
* **操作**: 黒板の落書きをタップして「チョークの粉」を集める。
* **ルール**: 新品の黒板消し、自動クリーナー、日直の手伝い、教頭先生の一喝などを購入して秒間収集を強化！

### 6. ⏱️ 10秒ピッタリ ＆ 反射神経テスト（1人〜友達対戦）
* **10秒ピッタリ**: 3秒後に表示が「?.???」に隠れるストップウォッチ！体内時計の限界に挑戦（誤差±0.05秒で神の称号）。
* **反射神経テスト**: 赤から緑に変わった瞬間に即タップ！ミリ秒（ms）単位で瞬発力を測定。

### 7. 🤔 究極の2択 ＆ ネタガチャ（友達と白熱議論）
* **内容**: 「一生給食が揚げパン vs カレーライス」「テスト全問ヤマが当たる vs 宿題一生免除」など盛り上がる2択が次々に出題！
* **ギミック**: 選択するとリアルタイム投票比率（%）が展開され、友達とどっち派かで盛り上がれる！

### 8. 🏫 席替えシミュレーター（クラス・席替え妄想）
* **操作**: 「🎲 席替え開始！」を押すとルーレット回転で30席を一斉シャッフル！
* **演出**: 「窓際一番後ろの主人公席」「教卓正面（唾飛び警戒席）」などの特等席ハイライト付き。

### 9. 🎨 うろ覚えお絵かきジャッジ（友達と爆笑クイズ）
* **操作**: ランダムなお題（ピカチュウ、非常口の人、校章など）に30秒タイマーで挑む！
* **演出**: 描き終えたら友達に見せて採点！画伯ぶりを笑い合おう。

## 🗣️ 休み時間の爆笑会話ゲーム（新登場！）

### 11. 🚫 カタカナーシ（カタカナ語禁止トーク）
* **操作**: 画面に出るお題（「スマホ」「ハンバーガー」等）を、**カタカナを一切使わずに**説明！

### 12. 🤐 言わせろ！NGワードバトル（2〜5人・心理誘導）

### 13. 🎤 エピソードトークガチャ（すべらない話）

* **機能**: 1分トークタイマー付きで友達の秘蔵エピソードを引き出せます。

### 14. 🕵️ 2つの真実と1つの嘘（ライアーゲーム）

### 15. 🏆 偏見プロフィールメーカー（勝手に鑑定書）
* **操作**: 友達の名前を入れてボタンを押すだけ！
* **機能**: 「前世はナマケモノ」「カバンの中に3ヶ月前のプリントが化石化」など、勝手な偏見が3連発で認定書として表示されます。

### 16. 💬 アニメ名言ダウト！（実在？架空？全60問収録！）
* **操作**: 画面に出るセリフを見て「⭕ 実在する！」「❌ 言ってない（架空）！」をタップ！
* **ギミック**: 『SLAM DUNK』『ONE PIECE』『呪術廻戦』『鬼滅の刃』『エヴァ』などの本物の名言と、「いかにも言いそうだけど完全な偽物」を見破る白熱クイズ！10問挑戦でアニメ生き字引ランク判定！
